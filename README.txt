WASIMDEV.ME SEO SITE
====================

Upload the contents of this folder to your hosting root.

Routes:
https://wasimdev.me/
https://wasimdev.me/about
https://wasimdev.me/projects
https://wasimdev.me/security
https://wasimdev.me/blog

After deployment:
1. Verify https://wasimdev.me/ loads.
2. Verify /robots.txt and /sitemap.xml.
3. Add https://wasimdev.me/ to Google Search Console.
4. Submit sitemap.xml.
5. Request indexing for each URL.
6. Replace placeholder social links with your real profiles.
7. Add real project/blog content as you publish it.

If your host does not support extensionless routes automatically, configure clean URL rewrites so
/about -> /about/index.html
/projects -> /projects/index.html
/security -> /security/index.html
/blog -> /blog/index.html
